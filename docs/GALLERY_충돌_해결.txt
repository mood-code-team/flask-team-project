================================================================================
  gallery 충돌이 "자꾸" 날 때 (팀원용)
================================================================================

■ 왜 반복되나요?

  1) git pull → gallery.py 충돌 → 수동/스크립트로 해결 → commit
  2) git stash pop → stash 안의 "예전 gallery 코드"가 다시 적용됨
  3) 또 gallery.py 충돌 → 1번으로 돌아감  (무한 반복)

  stash에 gallery 수정이 들어 있으면 pop 할 때마다 같은 파일이 충돌합니다.

■ 한 번에 끊는 방법 (추천)

  프로젝트 폴더에서:

    powershell -File scripts/resolve_frontend_pull_conflict.ps1

  이 스크립트는:
  - gallery 2파일을 GitHub frontend 최신본으로 맞춤
  - stash pop 후 gallery가 또 충돌해도 → 다시 원격본으로 덮어씀
  - gallery 말고 다른 파일 작업만 stash에서 살림

■ 그래도 안 되면 (frontend 브랜치에서 로컬 commit 없을 때)

    git merge --abort
    git stash clear
    git fetch team frontend
    git checkout frontend
    git reset --hard team/frontend

  ⚠ 로컬 commit / stash 전부 사라집니다. 다른 작업 백업 후 실행.

■ 앞으로 충돌 안 나게

  - routes/gallery.py
  - services/gallery_service.py

  이 두 파일은 내 PC에서 직접 수정하지 마세요.
  frontend에 올라온 걸 pull만 하세요.

  gallery 말고 다른 작업만 할 때:
    git stash push -m "작업" -- . ":(exclude)routes/gallery.py" ":(exclude)services/gallery_service.py"
