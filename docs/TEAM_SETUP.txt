Mood Code — 팀원 설치 · 실행 가이드
=====================================

저장소: https://github.com/mood-code-team/flask-team-project


■ 0. 미리 준비

  - Python 3.10+
  - Git
  - 확인: python --version  (또는 py --version)


■ 1. 코드 받기 (최초 1회)

  git clone -b frontend https://github.com/mood-code-team/flask-team-project.git
  cd flask-team-project

  ※ 이미 clone 했다면 frontend 브랜치로 맞추기:
    git checkout frontend
    git pull origin frontend


■ 2. 실행

  [Windows]
    실행_서버.bat 더블클릭
    → pip install, .env 생성, DB 없으면 seed, 서버 시작을 자동 처리

  [Mac / Linux]
    chmod +x run.sh
    ./run.sh

  [터미널 직접 — 반드시 ① 패키지 설치 후 ② 서버 실행]

    cd flask-team-project
    pip install -r requirements.txt
    python hspace_server.py

  ※ python hspace_server.py 만 실행하면 ModuleNotFoundError 가 날 수 있음
  ※ Windows 에서는 실행_서버.bat 사용을 권장 (자동 설치)

■ GitHub frontend 브랜치에 포함된 것 (pull만 하면 됨)

  data/csv/                    → 스크래핑 CSV + 이미지
  database/shop.db             → 상품 DB (670개+)
  static/images/products/      → import된 상품 이미지
  data-analysis/*.py           → 스크래핑·정제 스크립트

■ GitHub에 없는 것 (각자 PC)

  .env              → .env.example 복사 (bat/run.sh가 자동 생성)
  venv/             → 각자 선택


■ 자주 막히는 경우

  Python not found
    → Python 재설치, "Add Python to PATH" 체크

  상품·카테고리가 비어 있음 (또는 30개만 보임)
    → frontend pull 후 database/shop.db 가 있어야 함 (637개+)
    → shop.db 가 없으면: python scripts/seed_db.py
    → CSV 전체 재반영: python scripts/import_csv.py

  git pull 후 갤러리·카테고리가 이상함
    → git checkout frontend && git pull origin frontend
    → 서버 재시작 후 Ctrl+F5 (브라우저 캐시)

  ModuleNotFoundError (flask 등)
    → Windows: 실행_서버.bat (venv 자동 생성)
    → Mac/Linux: ./run.sh
    → 또는: pip install -r requirements.txt

  Mac에서 .bat 안 됨
    → ./run.sh 사용

  5000 포트 사용 중
    → 실행 중인 서버 Ctrl+C 종료

  설치 확인 (선택)
    → python scripts/team_smoke_test.py
    → [OK] 가 나오면 pull·DB·주요 페이지 정상

■ 수정 후 올리기

  git add .
  git commit -m "수정 내용"
  git push

  main에 직접 push가 안 되면:
    git checkout -b feature/내이름-작업
    git push -u origin feature/내이름-작업
    → GitHub에서 Pull Request 생성
